# DevOps Capstone Project - Customer Accounts Microservice

**Author:** mahesh1104-alt

**Status:** Active Development (Agile Planning Phase)

## Project Overview
This repository contains the microservice for managing Customer Accounts as part of the DevOps Capstone course. The service provides RESTful endpoints to create, read, update, delete, and list customer profiles, integrated with automated testing, CI/CD pipelines, containerization, and monitoring.

## Microservice Architecture & Capabilities
- **RESTful API:** Exposes endpoints for complete account lifecycle management.
- **Data Persistence:** Relational database integration for customer record state.
- **Agile Methodology:** Tracked using GitHub Projects and ZenHub-compatible Kanban workflows.
- **Test-Driven Development (TDD):** Unit tests and behavioral tests (Behave/BDD).
- **Deployment:** Docker containerization and Kubernetes orchestration.

## Agile Workflow Structure
- **Product Backlog:** Prioritized list of functional features and technical debt.
- **Sprint Cadence:** Estimated using modified Fibonacci story points (3, 5, 8, 13).
